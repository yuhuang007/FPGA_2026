# GitHub 入库范围

本仓库是可浏览的项目归档，原始工作区和大文件仍在 `D:\FPGA`。仓库包含 FPGA/香橙派源码、RTL 仿真、`FPGA_GS/FPGA_GSV1/release/` 下此次归档的全部发布文件、开发交接资料、现场实拍与代表性模型和验证材料。

优先用首页列明的两套重点冻结版本（3.6.1、3.5.9-R0）构建。其余日常工作目录和上位机历史轮次以源码及代表性证据为主，未保留所有二进制、训练评审图或运行环境。

软件安装包、主机授权、虚拟环境、训练原始数据集、可重新生成的构建中间件和重复迁移归档不随 Git 克隆。作品介绍、`SC_BT.mp4`、`SC_BT2.mp4` 和夜间样片采用更小的完整时长版本，其本地原片未被覆盖。

RKNN Toolkit2 如需查阅，用 `git submodule update --init FPGA_GS/FPGA_GSV1/orangepi/m404/toolkit_source` 拉取固定的上游版本。历史脚本中的设备地址、旧盘符和工具路径须按实际环境核对。
