# GitHub 入库范围

本仓库是可浏览的项目归档，原始工作区和大文件仍在 `D:\FPGA`。仓库包含 FPGA/香橙派源码、RTL 仿真、两套通过发布清单校验的重点冻结版本（3.6.1、3.5.9-R0）、开发交接资料、现场实拍与代表性模型和验证材料。

大包传输中断后，按源码优先补入了尽可能多的内容；部分历史冻结目录仅收录了现有源码和证据，它们的原始清单可能包含未入库文件。优先用首页列明的两套冻结版本构建，不要将历史目录直接当作完整工具包。

软件安装包、主机授权、虚拟环境、训练原始数据集、可重新生成的构建中间件和重复迁移归档不随 Git 克隆。大体积演示和道路录像收录了更小的完整时长版本，原片未被覆盖。

RKNN Toolkit2 如需查阅，用 `git submodule update --init FPGA_GS/FPGA_GSV1/orangepi/m404/toolkit_source` 拉取固定的上游版本。历史脚本中的设备地址、旧盘符和工具路径须按实际环境核对。
